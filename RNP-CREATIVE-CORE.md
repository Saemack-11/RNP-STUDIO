# RNP Creative Core 1.0

## Identity
Real Ninja Poetics is grown-man survival music—rugged storytelling, quiet motivation, slick humor, spiritual reflection, and intimate records for women who value genuine connection. It carries love and darkness honestly without glorifying destruction or pretending to be something Sae is not.

**Creative compass:** Pour into the woman. Speak to the soul. Admit the shadow. Never fake the story.

## Default creation flow
The visible creation surface should remain five steps:
1. Upload instrumental.
2. Pick one mode: Freestyle, Hook Ideas, Full Song.
3. Pick one energy: Rugged Reflection, Motivational Pressure, Grown-Woman Vibe, Scorpio Shadow.
4. Add one sentence about what is on Sae's mind.
5. Generate.

Everything nonessential belongs under Advanced.

## Creative Core API
`POST /api/creative-core`

Required request fields: `mode`, `energy`, `thought`.
Optional: `truth`, beat metadata, adaptive profile signals.

Every pass returns: beat read, exactly three hook directions, song structure, opening bars, story prompts, flow/delivery cues, optional punchlines, optional harmonies, mode-specific creative output, and authenticity checks.

## Adaptive learning contract
Store explicit decisions rather than silently guessing identity. Signals include: kept output, rejected output, user rewrites, material actually recorded, vocabulary, avoid-list, humor notes, rhyme-density notes, and beat styles that produced strong sessions.

Recommended UI feedback controls on generated material: Keep, Rewrite, Too AI, Not Me, More Humor, More Personal. A recorded/used signal should carry more weight than a generation or view.

Adaptive data is preference context only. It never authorizes invented biography or facts.

## Energy guardrails
- Rugged Reflection: scars, rebuilding, fatherhood, isolation, consequences, quiet power.
- Motivational Pressure: discipline and earned confidence without slogans or preaching.
- Grown-Woman Vibe: sensual, reassuring, admiring, respectful; never degrading.
- Scorpio Shadow: controlled darkness, discernment, loyalty and boundaries; never revenge fantasy or fake toxicity.

## Product rule
High-tech behind the curtain, dead simple in Sae's hands. Existing Council, Culture Pulse, memory, voice memo, finishing and advanced tools can remain available, but they must not crowd the primary creation path.
