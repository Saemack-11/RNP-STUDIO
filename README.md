# RNP Studio 6.0 — Adaptive Intelligence

Completion build adds:
- Beat-locked Adaptive Predictive Bars
- Verse, Hook and Adlib modes
- Voice Memo upload, local waveform, playback and server transcription
- A cappella and beat-backed memo workflow
- Quick Council strategy review
- Nostalgia Reference Only vs Influence Bars
- Culture Vault context inside predictions
- No Cap Guard
- RNP Inspiration Equalizer with semantic presets and eight influence bands
- Use, preview and rework actions for every predicted bar
- Existing full-track generation, Vocal Lab, Mixer, Cover Studio, Culture, Memory and Archive preserved

Deployment requirements:
- OPENAI_API_KEY
- Optional OPENAI_MODEL (defaults to gpt-5-mini)
- Optional OPENAI_TRANSCRIBE_MODEL (defaults to gpt-4o-mini-transcribe)

Literal private voice cloning is intentionally not activated in this build. Voice Memo Intelligence and pattern adaptation are complete; a private generated-voice enrollment flow requires an eligible custom-voice account, consent capture and secure model storage.
